# File Preview

一个简洁的 Windows 本地文件预览工具。拖入文件即可查看，不需要安装 Office、WPS 或其他转换软件，也不需要联网。

## 下载与安装

适用于 Windows 10 / 11，64 位系统。可选择以下两种方式：

| 文件                                | 使用方式                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| `FilePreview-Setup-3.3.0-x64.exe`   | 双击安装，选择安装位置，完成后从桌面或开始菜单打开（默认发布产物）              |
| `FilePreview-3.3.0-Windows-x64.zip` | **完整解压**到一个文件夹，双击其中的 `File Preview.exe`；请保留同目录的资源文件（可选免安装包） |

安装包尚未进行商业代码签名。下载来源请认准本项目的 [GitHub 仓库](https://github.com/Linn924/filePreview)。

窗口标题显示“文件预览”，内部不再显示左上角品牌图标与文字。

## 打开文件

- 点击首页中央的打开区域，或直接拖入文件。
- 按 `Ctrl + O` 选择文件，可一次选择多个。
- 文件在新的预览窗口打开，默认最大化；顶部显示文件名和大小。
- 安装版支持在资源管理器中右击文件 → **打开方式** → **File Preview**。若列表中没有显示，选择“选择其他应用”，找到安装目录中的 `File Preview.exe`。
- 解压版也可通过“选择其他应用”指定其 `File Preview.exe`。只有主动选择“始终使用”才会更改默认打开方式。
- 软件已经运行时，通过“打开方式”继续打开的文件会交给现有软件处理。

首次同时打开多个文件时，可以选择：

- **一个窗口，标签切换**：每个文件占一个标签，点击切换，拖动标签调整顺序，点击标签上的 × 关闭该文件。
- **每个文件一个窗口**：便于把不同文件放到不同显示器或并排查看。

软件会记住这次选择，以后可在右上角设置中更改。将文件标签拖到另一个预览窗口即可合并；目标窗口接收成功后，原标签自动移除，空的源窗口自动关闭。标签保留缩放倍率并恢复可用的滚动位置，取消拖动不会移动文件。

在预览窗口的标签栏右侧有 **「+ 打开」**：点击或按 `Ctrl + O` 可继续选择文件，并作为**当前窗口的新标签**打开（已打开的同一次选择不会重复添加同一 ID）。首页的打开方式仍会按「多文件打开方式」创建标签页或独立窗口。

多文件时：**点击标签**切换；在**标签栏上滚动滚轮**切换上一个/下一个；当前文档已滚到顶/底后再继续滚轮，也会切换到上一个/下一个文件。

## 支持的文件

| 类型       | 格式                                                     | 可以查看的内容                                                                      |
| ---------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Word       | `.docx`、`.doc`                                          | 文字、图片、表格；DOCX 连续滚动与打印 |
| Excel      | `.xlsx`、`.xls`、`.csv`、`.tsv`                          | 合并区域、虚拟滚动、定位单元格、冻结首行/首列 + 额外 N 行/列 |
| PowerPoint | `.pptx`、`.ppt`                                          | 幻灯片文字、图片和静态布局 |
| PDF        | `.pdf`                                                   | 页面预览、搜索、目录/缩略图、密码、旋转、打印 |
| 文本 / 代码 | `.txt`、`.json`、`.md`、`.xml`、`.log`、`.js`、`.ts`、`.css`、`.ini`、`.yaml` 等 | 行号、搜索、多语言着色 |
| 图片       | `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`、`.bmp`、`.svg` | 适配、原始像素、旋转、EXIF 方向、可打印 |

复杂 Office 文档的图表、特殊字体、SmartArt、动画等内容可能与 Office 不完全一致。PPT 以静态预览为主；旧 DOC/PPT/XLS 的排版还原能力弱于新版格式。未安装的字体会使用系统可用字体替代。

## 翻页与缩放

PDF 优先显示第一页，其余页面尺寸在后台分批补齐；总页数可立即用于跳转，混合横竖版页面按各自真实比例显示。后台补齐期间滚动条长度可能调整。

- Word、PDF、PPT 各页纵向连续排列，鼠标滚轮自然向下阅读下一页，向上返回前文。滚轮不再缩放或直接切页。
- 右下角页码跟随滚动位置更新。“上一页”“下一页”滚动定位到对应页面，其他页面仍保留在连续内容中。
- 顶部 `−`、`+` 可以调整倍率；点击数值可输入 **25%–400%** 的自定义倍率，按回车或离开输入框生效。
- “适配”恢复到当前适配方式下的 100%。可在设置中更改默认倍率。
- 页码输入框在底部居中操作区（Word、PDF、PPT 与 Excel 行分组均支持）。
- PDF 工具栏可打开**搜索**（Enter 或「查找」，上一处/下一处跳转）与**目录/缩略图**侧栏。搜索命中页会高亮标记；打开搜索后可在页面上选择文字并复制。无书签的 PDF 会提示「本文档没有目录/书签」。扫描/纯图片 PDF 可能搜不到文字。
- PDF 支持**临时旋转**（0°/90°/180°/270°，不修改源文件）。受密码保护的 PDF 会提示输入打开密码，密码仅用于本次内存解密，不写入设置。
- Excel 行虚拟滚动：仅渲染可视区域附近的行，上万行表格滚动更省 DOM；支持定位单元格（如 B12）与冻结首行/首列、额外冻结 N 行/列。
- Word 表格临时列宽会随标签跨窗口拖拽迁移（与 Excel 同类状态一致）。
- 预览标签固定宽度，悬停可看完整文件名；标签栏滚轮或滚到文档顶/底可切换文件。
- 常用操作多为**图标按钮**（打印、搜索、查找/上一处/下一处、目录/缩略图、旋转、沉浸、上一页/下一页、打印列表上移/下移/移除/设置），悬停可见说明。
- 应用图标为蓝底白纸与预览镜（文档眼）样式。

## 沉浸式全屏阅读

点击“沉浸阅读”或按 F11，当前预览窗口覆盖任务栏并隐藏系统标题栏，收起标签栏和工具栏，让内容区域占满屏幕。鼠标移到屏幕上边缘可显示工具栏，下边缘显示页码；按 Esc 或 F11 退出。退出后恢复进入前的缩放、适配方式和滚动位置，其他窗口不受影响。

Word、PDF、PPT 和图片提供：

- **适合宽度**：按窗口宽度等比显示，较长页面通过滚动查看。
- **整页适配**：将完整页面或图片等比放入窗口，比例不同会保留留白。
- **默认显示**：回到原有显示方式。

进入沉浸模式时，上述类型默认整页适配。选择适配方式会将倍率重置为 100%；之后仍可输入倍率调整大小。Excel 和文本继续使用连续滚动阅读，不虚构纸张页面。

## PDF 打印与批量打印

仅 PDF / 图片 / DOCX 提供打印。工具栏为**打印机图标**（悬停提示「打印」），点击打开独立、可移动和缩放的打印设置窗口。原预览窗口仍可操作；点击「并排查看」可左右摆放，也可将打印窗口拖到其他显示器。

点击打印图标时，设置中可选择列表如何填充：

| 设置选项 | 行为 |
| -------- | ---- |
| 本窗口全部 PDF（默认） | 把该预览窗口中已打开的所有 PDF 标签加入打印列表（已存在的不重复） |
| 仅当前文件 | 只加入当前正在预览的这个文件 |
| 不自动加入 | 只打开打印窗口，再手动「添加文件」或拖入 |

1. 自行选择打印机、纸张（**A3 / A4 / A5 / A6 / Letter / Legal**）、横向或纵向、份数、彩色或黑白、单双面。纸张与方向由用户决定，软件不会根据文档自动替换。
2. **缩放**：适合纸张 / 实际大小 100% / 仅缩小（不放大）。**页序**：顺序 / 逆序 / 仅奇数页 / 仅偶数页（在页码范围之后应用）。
3. 页码留空表示全部；输入 `1-3,5` 可仅打印指定页。
4. 每个文件默认只显示一行摘要（如 `A4 纵向 · 1 份 · 全部页`）；点「设置」展开纸张、方向、份数、单双面、颜色、缩放、页序、页码，以及原页尺寸列表。支持勾选、排序、移除、「应用到全部」。
5. 勾选后点「打印所选文件」提交。状态为**已提交到系统队列**，是否出纸请打开「系统打印机」确认。若打印机不支持所选纸张（例如仅有 A4 却选 A5），会提示改用 A4 或在驱动中启用该尺寸。
6. 「停止后续任务」在当前任务结束后停止；已进入系统队列的任务请在 Windows 打印队列中取消。

点击打印列表里的文件名，原预览窗口会切换或打开对应 PDF；如果原窗口已关闭，会重新创建预览。展开设置后显示原页尺寸列表与**纸张排版示意**；屏幕显示大小不代表真实纸张大小。打印窗口内可直接拖入文件。关闭打印设置窗口后释放本次列表和参数，不保留历史。

打印按所选纸张等比居中，保留约 10 mm 页边距，使用白色页面；不打印预览工具栏，不受黑夜主题和阅读缩放影响。打印机和驱动需支持所选纸张与双面模式。超大打印任务会提示按页码范围分批打印。

应用不保存打印转换副本；Windows 打印后台可能产生系统缓存。若自行选择虚拟 PDF 打印机，输出保存由该打印机处理。

## 查看宽表格

Excel 的列标题边缘、Word 表格第一行的单元格右边缘可拖动，临时拉宽列以查看内容。宽表格可使用横向滚动条。

Excel 随向下滚动继续加载后续行，不必切页才能读取下一组数据。底部行分组支持定位；宽表格仍可切换每组 100 列，所有列均可访问。Sheet 标签切换工作表。列宽调整只影响本次预览，不修改原文件。

## 设置与关闭

点击右上角齿轮打开设置：

| 设置           | 作用                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 外观           | 白天、黑夜、跟随系统；文档页面保留自身颜色；黑夜图片背景采用柔和深灰 |
| 关闭首页 ×     | 每次询问、退出软件、隐藏到托盘                                       |
| 多文件打开方式 | 首次询问、同一窗口标签页、多个独立窗口                               |
| 默认缩放       | 新打开文件的起始倍率                                                 |
| 预览窗口最大化 | 新预览窗口默认铺满桌面工作区，保留系统标题栏                         |
| 点击“打印 PDF”时列表 | 本窗口全部 PDF（默认）、仅当前文件、不自动加入               |

第一次点击首页窗口 × 时，会询问是**退出软件**还是**隐藏到托盘**，也可以取消。勾选“记住我的选择”后，以后直接执行所选操作。

退出软件会关闭所有预览；隐藏到托盘会保留当前窗口，点击右下角眼睛图标可恢复，右击托盘图标也可以退出。预览窗口的系统 × 直接关闭该窗口及其中的标签，不弹退出提示，不影响其他窗口或源文件。关闭单个标签也可点击标签上的 ×。

## 文件与隐私

跨窗口移动标签会携带适配方式、文本编码及 Excel 当前工作表、列分组、已加载行和临时列宽；这些阅读状态仅在内存中保留，退出后不恢复。XLSX 样式解析失败但单元格数据可读取时，会显示基础表格和降级提示。受密码保护、损坏、缺失或无读取权限的文件会显示对应处理建议；密码输入暂不支持。

所有文件均在本机内存中读取和预览，不上传，不保存预览文件、转换副本或最近打开记录。关闭文件会释放相应预览资源。

软件只保存外观、关闭方式等应用设置，设置中不包含文件内容或历史路径。单文件上限为 100 MB，文本上限为 5 MB；暂不限制多选文件、打印批次文件及预览窗口的数量。
