# File Preview

一个简洁的 Windows 本地文件预览工具。拖入文件即可查看，不需要安装 Office、WPS 或其他转换软件，也不需要联网。

## 下载与安装

适用于 Windows 10 / 11，64 位系统。可选择以下两种方式：

| 文件                                | 使用方式                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------- |
| `FilePreview-Setup-3.0.0-x64.exe`   | 双击安装，选择安装位置，完成后从桌面或开始菜单打开                              |
| `FilePreview-3.0.0-Windows-x64.zip` | **完整解压**到一个文件夹，双击其中的 `File Preview.exe`；请保留同目录的资源文件 |

安装包尚未进行商业代码签名。下载来源请认准本项目的 [GitHub 仓库](https://github.com/Linn924/filePreview)。

## 打开文件

- 点击首页中央的打开区域，或直接拖入文件。
- 按 `Ctrl + O` 选择文件，可一次选择多个。
- 文件在新的预览窗口打开，默认最大化；顶部显示文件名和大小。
- 安装版支持在资源管理器中右击文件 → **打开方式** → **File Preview**。若列表中没有显示，选择“选择其他应用”，找到安装目录中的 `File Preview.exe`。
- 解压版也可通过“选择其他应用”指定其 `File Preview.exe`。只有主动选择“始终使用”才会更改默认打开方式。
- 软件已经运行时，通过“打开方式”继续打开的文件会交给现有软件处理。

首次同时打开多个文件时，可以选择：

- **一个窗口，标签切换**：每个文件占一个标签，点击切换，拖动标签调整顺序，点击标签上的 × 关闭该文件。
- **每个文件一个窗口**：便于把不同文件放到不同显示器或并排查看。

软件会记住这次选择，以后可在右上角设置中更改。当前支持同一窗口内标签排序；跨窗口拖动合并暂未实现。

## 支持的文件

| 类型       | 格式                                                     | 可以查看的内容                                                                      |
| ---------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Word       | `.docx`、`.doc`                                          | 文字、图片、表格和文档排版；DOCX 按渲染页面翻页                                     |
| Excel      | `.xlsx`、`.xls`                                          | 工作表切换、单元格数据、合并区域；XLSX 尽量保留字体、颜色、数字格式、行高列宽和图片 |
| 表格文本   | `.csv`、`.tsv`                                           | 以表格形式查看数据                                                                  |
| PowerPoint | `.pptx`、`.ppt`                                          | 幻灯片文字、图片和静态布局，逐页查看                                                |
| PDF        | `.pdf`                                                   | 内嵌页面预览、页码跳转和缩放                                                        |
| 文本       | `.txt`、`.text`、`.log`、`.xml`                          | 原文查看、编码选择                                                                  |
| JSON       | `.json`                                                  | 格式化显示；格式不正确时仍可查看原文                                                |
| Markdown   | `.md`                                                    | 排版预览或原文查看                                                                  |
| 图片       | `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif`、`.bmp`、`.svg` | 适配窗口、尺寸信息和缩放                                                            |

复杂 Office 文档的图表、特殊字体、SmartArt、动画等内容可能与 Office 不完全一致。PPT 以静态预览为主；旧 DOC/PPT/XLS 的排版还原能力弱于新版格式。未安装的字体会使用系统可用字体替代。

## 翻页与缩放

- **鼠标在内容页上**：向上滚轮放大，向下缩小；顶部倍率同步更新。
- **鼠标在内容页外的空白区域**：Word、PDF、PPT 翻到上一页或下一页，底部页码同步；Excel 切换行分页。连续长文也可以拖动滚动条浏览。
- 顶部 `−`、`+` 可以调整倍率；点击数值可输入 **25%–400%** 的自定义倍率，按回车或离开输入框生效。
- “适配”恢复到 100% 的初始显示。可在设置中关闭内容滚轮缩放，或更改默认倍率。
- PDF / PPT 可使用底部按钮翻页，PDF 还可输入页码跳转；Word 的底部页码跟随当前渲染页。

## 查看宽表格

Excel 的列标题边缘、Word 表格第一行的单元格右边缘可拖动，临时拉宽列以查看内容。宽表格可使用横向滚动条。

Excel 每次显示最多 200 行、100 列，通过底部行分页和列分组访问其余数据；**不是只读取前 200 行或前 100 列**。Sheet 标签可以切换工作表。列宽调整只影响本次预览，不修改原文件。

## 设置与关闭

点击右上角齿轮打开设置：

| 设置           | 作用                                         |
| -------------- | -------------------------------------------- |
| 外观           | 白天、黑夜、跟随系统；文档页面保留自身颜色   |
| 点击窗口 ×     | 每次询问、退出软件、隐藏到托盘               |
| 多文件打开方式 | 首次询问、同一窗口标签页、多个独立窗口       |
| 默认缩放       | 新打开文件的起始倍率                         |
| 预览窗口最大化 | 新预览窗口默认铺满桌面工作区，保留系统标题栏 |
| 内容滚轮缩放   | 开启或关闭鼠标在内容区域的滚轮缩放           |

第一次点击窗口 × 时，会询问是**退出软件**还是**隐藏到托盘**，也可以取消。勾选“记住我的选择”后，以后直接执行所选操作。

退出软件会关闭所有预览；隐藏到托盘会保留当前窗口，点击右下角眼睛图标可恢复，右击托盘图标也可以退出。关闭单个文件请使用其标签上的 ×。

## 文件与隐私

所有文件均在本机内存中读取和预览，不上传，不保存预览文件、转换副本或最近打开记录。关闭文件会释放相应预览资源。

软件只保存外观、关闭方式等应用设置，设置中不包含文件内容或历史路径。单文件上限为 100 MB，文本上限为 5 MB；一次最多选择 12 个文件，最多同时打开 25 个窗口。
