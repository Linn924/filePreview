# PDF 全链路审查与统一优化方案

日期：2026-09-28。范围：现有 PDF 阅读与打印的性能、正确性及资源生命周期；不新增阅读功能，不打包安装，不连接实体打印机。

## 完整审查与决策

| 链路 | 当前证据 / 现状 | 决策与改法 | 关联影响、收益与代价 |
| --- | --- | --- | --- |
| 文件读取 | fs Buffer 转 Uint8Array 再复制；相同 ID 并发请求会重复读文件；路径没有随最后使用者清理 | 必须完善引用生命周期；值得优化：复用完整自有 Buffer，池化/切片 Buffer 保留一次必要复制，按 ID 合并读取，关闭时取消读与回填 | 所有格式共享读取层，须回归受影响格式；IPC 的安全复制仍保留，打印列表/移交不丢有效文件 |
| 原始字节缓存 | 按源大小计费，命中不调整访问顺序；视图与解析器另占内存 | 值得优化：修正字节缓存访问顺序；只保留一份必要 worker 传输副本 | 不把缓存预算当进程内存上限；更少复制不改变源文件 |
| 文档缓存 | 已有去重、使用凭据及 8 份/384 MB 闲置预算 | 必须完善：失败/关闭/加载中取消、短时闲置清理；缓存页面尺寸和文字提取 | 防止关闭后后台解析残留；缓存命中省重复工作，闲置超时可能重解析 |
| 解析与任务队列 | 两通道且后台最多一通道，但排队任务不能直接移除；每份文档启动自己的解析 worker | 值得优化：同窗口复用 worker，各文档保留独立 transport；取消排队任务，执行前检查存活状态；正文优先 | 减少批量文件 worker 启动/代码驻留；不能销毁其他活动文档；已执行的非可取消提取只能忽略结果 |
| 正文画布 | 单画布 600 万像素；离屏重绘期间双份像素；刷新清空绘制记录后旧画布失去跟踪 | 必须修复：统一跟踪显示/临时画布，按窗口总像素预算分配，离屏和关闭显式释放 | 保留无闪白效果；多窗口或极高缩放下自适应降低预览像素，CSS 比例不变 |
| 文字层 | 每个 span 单独插入；缩放重复提取/建层；大量 span 一次处理；选中框没有完整旋转/字体宽度矩阵 | 必须修正选中框方向；值得优化：共享提取，分片创建、Fragment 提交，构建代次取消与字体测量状态复用 | 保留选择/链接/高亮；需要验证密集文字与旋转对齐；透明文字层不改变源页面视觉 |
| 缩略图/目录 | 元数据读取不完全调度，卸载时未显式释放全部历史画布；目录父链反复线性查找 | 必须释放所有缩略图；值得优化：过期任务取消、尺寸去重、目录索引 | 防止离屏位图累积；侧栏拖宽仍保留即时反馈 |
| 搜索 | 源文本规范化与 span 偏移不完全一致；concat 仍复制全表；32 页缓存限制按数量 | 必须统一文本映射并显式清理高亮；值得优化：追加坐标结果与字符预算、少量批次发布、取消排队提取 | 不静默截断命中数量；保留原扁平游标契约，省去摘要与逐条响应式代理；结果仍随命中数增长 |
| 布局 | 每批尺寸变动重算全篇 offsets；每次挂载重新扫描 | 值得优化：缓存每页尺寸、增量前缀位置索引，缩放/适配全量重算一次 | 混合纸张跳页保持锚点；增加小型索引及专项断言 |
| 多窗口 | 每个渲染进程预算各自独立；窗口数增多时总占用相加 | 值得优化：主进程协调 PDF 渲染窗口预算，窗口关闭后回收份额 | 限制应用管理的画布/闲置缓存，不限制 Electron 基础内存和源文档必须占用 |
| 打印 | 已复用隐藏窗口；每份独立解析，150 DPI，计划像素上限 6000 万；独占任务字节仍多复制一次；CSS 会再次缩小实际大小 | 必须修正实际大小：仅栅格化可打印裁剪区域，示意共用同一算法；保留引擎，强化任务标识、防迟到通知、异常释放；轮到任务时读取并直接转交独占 worker | 保持 A4/A5、方向、范围和顺序隔离及 150 DPI；单份长打印仍需分范围；实际大小超出纸张时居中裁切 |
| 权限/关闭/失败 | 当前 PDF.js 权限返回 Set，却按单个数值判断；工具栏与阅读模块上下文不同；多个 await 后无统一代次检查 | 必须修正基本打印许可判断与状态发布，统一会话解锁状态、清理计时器/帧/监听器、验证迟到结果代次 | 不把高质量标志当作基本许可；真实加密样例验证；密码仅在本次文件引用会话内，不写设置 |

## 实施结果与参数

上述必要修复与值得优化项在同一批实现，不保留为下一轮待办：

- 读取/引用：`electron/files.ts` 负责合并读取、AbortSignal、完整 backing buffer、窗口/打印列表引用和会话密码；`transfers.ts` 在移交确认时先保留目标引用再关闭来源。原始字节缓存命中更新 LRU。未激活标签不启动解析。
- 解析/缓存：`docCache.ts` 使用凭据、并发去重、共享 worker、30 秒闲置回收；构造异常、加载中关闭、密码替换都会释放，活动文档保持独立 transport。
- 预算：主进程 `pdfResources.ts` 为已注册 PDF 窗口分配参考额度：画布总额 4800 万像素、单窗口最多 2400 万；源字节参考总额 384 MB，解析缓存与字节缓存各自计费；闲置文档参考总额 8 份，单窗口至少一份。活动大文件、最低文档份额、预算变化中的正在执行任务属于必要例外，不是整个软件的硬内存上限。
- 位图：`canvasPool.ts` 跟踪正文、缩略图、示意与临时位图；显示与离屏画布同时计费，滑出、替换、隐藏和关闭显式释放。正文仍有单页 600 万像素限制，长边再限制为 8192 像素；资源不足时保留 CSS 比例并降低预览像素。
- 文字/搜索：共享最多 32 页、估算 4 MB 的 TextContent 缓存；搜索字符串最多 32 页、约 2 MB（必要单页可超）。每 200 项提交一批 DOM，复用字体测量状态，应用 viewport 与文字矩阵。命中仅存页码/原始偏移/长度，非响应式逐条数据在批次末通知，界面只接收计数；保留所有命中，不复制无用摘要。清空与切换查询取消旧结果、解绑高亮，迟到定位无效。
- 布局：`pageIndex.ts` 增量前缀树使尺寸修正/定位为 O(log N)，缩放或真正影响适配的尺寸变化再整体重建；仅预算改变不重建文字层。页面尺寸共享缓存，后台优先阅读附近、每批最多 64 页。批注按页索引，编辑合并保存，并在卸载前保留最后状态。
- 打印：`print/rasterPlan.ts` 为示意与输出共用比例/裁剪算法；打印仍是 150 DPI、每份最多 6000 万计划像素，实际大小不再被 CSS 缩小；独占任务字节直接交给 worker。隐藏执行窗口复用但每份重新加载独立页面；每任务 UUID、consume 标志与回调身份检查，拒绝迟到/重复通知，失败销毁、闲置 1.5 秒释放。
- PDF 打印使用 PDF.js 的 print intent，完成栅格与字体准备后直接进入原生打印布局，不再等待隐藏窗口中的两次动画帧。图片/DOCX 既有路径保留并回归，打印分辨率不因此降低。

以上辅助逻辑均留在 PDF 模块；跨类型读取、窗口移交和打印契约留在共享/主进程层，App.vue 没有新增格式解析分支。

## 暂不改动及理由

- 不切换 PDF.js、Electron 或矢量打印引擎：属于兼容性重构，需要更多设备验收；本轮保持 150 DPI 与现有纸张行为。
- 不使用 worker 间共享可写字节或关闭隔离来追求“零复制”：安全和兼容性代价大，IPC/worker 的必要副本明确保留。
- 不自动拆分打印作业：会影响份数、双面与逐份装订语义；保留预算拒绝及用户指定范围。
- 不新增 OCR、双页视图或批注导出：属于功能扩展，不混入性能任务。
- 不承诺任意数量窗口下的整个软件内存硬上限：源文档解码、Electron 基础进程和驱动内存不能只靠画布预算控制。

## 验收标准与统一终点

先记录同机同样例基线，再在同一套场景复测。样例为公开结构的自生成测试文件，不保存用户文件。

| 场景 | 操作 | 必须满足 |
| --- | --- | --- |
| 批量单页发票 | 50 个标签，逐一打开并再次切换；打印 10 份 | 文件数量完整、参数独立、切换不丢状态，打印顺序正确 |
| 长文档 | 80 页横竖混合及更长样例，首/中/尾反复定位 | 页码准确，画布/DOM 有界，关闭后无活动任务或保留位图 |
| 扫描件 | 带图片页面连续缩放 25–400%、跳页 | 比例与像素非空正确，窗口画布总量有界，内存不随循环持续增加 |
| 密集文字 | 密集 span，搜索高频词、取消/换词/旋转 | 命中不丢、坐标对齐、取消后不回填，文字构建分片 |
| 多窗口 | 6 个独立 PDF 窗口，同时缩放与关闭 | 预算协调、活动文档不被误销毁，关闭后预算回收 |
| 打印生命周期 | A5 纵向/A4 横向、重复 ready、失败/关闭/超预算 | 一任务一提交、迟到事件无效、窗口释放、不接触实体打印机 |

记录开窗、逐次切换、缩放稳定、搜索、打印准备耗时（中位数/最大值），并以 50 ms 间隔记录 Electron 进程工作集之和及峰值。该值包含测试主进程/GPU/工具进程，是本机工作集样本，不是完整 GPU 显存或精确瞬时峰值。

功能与资源约束必须通过。性能回归门槛：与同机基线相比，耗时中位数不得增加超过 30% + 100 ms，工作集峰值不得增加超过 25% + 64 MB；超出时定位并修正，不能以功能通过替代。测量受系统噪声影响，不保证每项都下降，也不使用该阈值宣称提升幅度。

完成条件：本表全部链路有实施结果或明确保留理由、专项测试通过、前后测量记录齐全、README/架构/测试文档同步。剩余边界在本文件交付，不将本次已审查内容拆成下一轮清单。

## 本机对照结果

旧版基线为 `72a78f8`，在临时隔离源码中用当前性能脚本重新测量；前后相同样例、机器、采样间隔与测试后台节流设置。临时旧版源码测量后已移除，主工作区未切换/回滚。下面为成功完整运行的观察值，未完成、受遮挡暂停或超门槛的中间运行不作为验收通过记录。

| 场景 | 工作集峰值：前 → 后（MB） | 开窗单次：前 → 后（ms） | 其他耗时：前 → 后（ms） |
| --- | --- | --- | --- |
| 50 个单页发票标签 | 1360.7 → 722.4 | 904 → 325 | 逐一访问与回访的混合切换中位数 26 → 113 |
| 500 页混合尺寸 | 878.2 → 676.2 | 360 → 331 | 跳页中位数 2 → 4 |
| 12 页扫描图 | 859.3 → 661.3 | 265 → 370 | 缩放观察 264 → 265 |
| 20 页密集文字 | 963.0 → 810.5 | 347 → 383 | 20000 命中搜索 338 → 226 |
| 6 个独立窗口 | 1576.3 → 1518.3 | 1150 → 1132 | 缩放观察 267 → 267 |
| 10 文件打印（独立进程场景） | 1080.3 → 1065.0 | 392 → 385 | 每份准备中位数 2093 → 55 |

本轮阈值全部满足，未提高阈值。按需加载把成本从首次批量打开转移到首次切换；部分单文件开窗与切换观察变慢，不描述为每项都提速。50 标签样例工作集约减少 47%，这是该次测试进程工作集之和的结果，不是所有真实发票的固定降幅。打印数值仅到模拟系统出口的准备阶段，不能推断真实打印机出纸提速。

中间发现密集命中逐条响应式代理开销，以及隐藏窗口动画帧导致打印准备约 2–3 秒等待；前者改为坐标批次通知、后者改 print intent / 原生打印布局后复测。功能回归包含真实加密、字体方向、权限、资源释放、纸张尺寸、共享图片/DOCX 打印；共享读取层覆盖 Word/Excel/PPT/文本/图片和多文件套件。

## 交付边界（本轮明确保留）

- 合成样例覆盖数量/结构与生命周期，不代表全部真实文档、字体、复杂扫描图或驱动。开窗单次、100 ms 断言轮询与固定缩放观察等待不是精确的交互逐帧分布；工作集不是总 GPU 显存或完全瞬时峰值。
- 在资源额度内保留必要副本与活动文档；闲置字节可能继续缓存，预算转换中的正在执行渲染可短时跨过新额度。降低预览像素可能略柔和，内容比例与打印 DPI 保留。
- 后台阅读窗口允许系统节流；隐藏时恢复速度与必要内存保留属于取舍。测试单独关闭节流只用于可重复的活动阅读测量，不将其写入正常软件配置。
- 仍不改打印引擎、不自动拆分长作业、不对驱动/纸盒能力作硬件保证、不添加 OCR 或源文件编辑；这些均为前述保留决策，不是本次遗漏的新优化清单。
