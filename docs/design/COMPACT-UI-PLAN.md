# File Preview — 紧凑 Windows 桌面工具视觉方案（仅设计，未改产品代码）

**状态**：待确认  
**约束**：不改解析/业务逻辑；不打包；不推 GitHub；无在线字体/图标 CDN。

## 1. 现状主要问题（代码勘察）

| 问题 | 现状 | 影响 |
|------|------|------|
| 工具条过高 | `.filebar` ~52–68px，含 badge + 文件名 + 适配 + 缩放 + 打印 + 沉浸 | 内容区被压 |
| 信息重复 | 标签已有文件名，filebar 再展示完整名 + 大小 + EXT 徽章 | 啰嗦 |
| 页码条偏高 | `.page-nav` min 44–48px，左右说明多 | 底部浪费 |
| 首页空 | 大拖放区 + 格式胶囊，顶栏只有齿轮 | 像半成品 |
| 图标混用 | ⚙ ↑ ↓ × ⤒ 等字符 | 不统一、不清晰 |
| 打印页说明多 | 虽已精简，仍可再压层级 | 边看边调时噪音 |
| 圆角/阴影不一 | 6–16px 混用 | 不像系统工具 |
| 颜色分层 | `--bg/#eef1f6` 与 `--stage` 接近，舞台感弱 | 文档与壳粘连 |

**必须保留**：连续滚动、页码跟随、滚轮只滚不缩放、独立打印窗、全部已实现功能、文档自身配色。

## 2. 两套方案

### 方案 A — 接近原生 Windows（更“系统”）

```
┌─────────────────────────────────────────┐
│ 标签 □ file.pdf ▣  │ + │           ⚙   │  ← 36px 标签+窗控区
├─────────────────────────────────────────┤
│ [100%] 适配 宽度 │ 页 2/12 │ 打印 │ F11 │  ← 32px 工具条
├─────────────────────────────────────────┤
│                                         │
│            文档舞台（深一档灰）          │
│            白页居中，阴影极轻            │
│                                         │
└─────────────────────────────────────────┘
```

- 控件高 **28–32px**，圆角 **4px**，边框 1px，几乎无阴影  
- 强调色仅用于：选中标签底边、主按钮、焦点环  
- 字体：Segoe UI 12–13px 为主  
- 图标：16px 线性 SVG（打包内联，无 CDN）  

**适合**：大量 Office/文件夹用户，零学习成本。

### 方案 B — 现代紧凑（推荐）

```
┌─────────────────────────────────────────┐
│  ⬤ file.pdf  ⬤ 发票.pdf  +      ⚙ ⋯  │  ← 36px 标签条
├─────────────────────────────────────────┤
│ PDF │ 合同-最终版.pdf      128 KB       │  ← 28px 单行身份条
│ 90% − + │ 适合 宽度 整页 │ 12/48 │ 🖨 ⛶│  ← 36px 操作条
├─────────────────────────────────────────┤
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
│         ┌─────────────────┐            │
│         │   白页文档       │            │  ← 内容最大
│         └─────────────────┘            │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │
├─────────────────────────────────────────┤
│ 上一页   2 / 12   下一页                │  ← 28px 极简页码
└─────────────────────────────────────────┘
```

相对 A：
- 顶栏合并「标签 + 设置」，预览不再单独占 44px 空头  
- **身份条**一行：类型点 + 文件名截断 + 大小（悬停全名）  
- **操作条**：缩放组 | 适配组 | 页码（可点输入） | 打印 | 沉浸  
- 舞台底色更深一档（`--stage` 比 `--bg` 深约 8% 明度），白页对比清楚  
- 圆角统一 **6px**；主按钮 **28px 高**；图标 **16px**  
- 打印窗：顶栏打印机 + 文件列表卡片更扁，摘要一行，设置默认收起  

**为什么推荐 B**：阅读与边看边调打印是主场景——B 把垂直空间还给文档，同时保留原生可预期的操作条结构，不牺牲可发现性。

## 3. 推荐方案 B 的设计 Token

| 用途 | 白天 | 黑夜 |
|------|------|------|
| 窗口底 `--bg` | `#F3F5F8` | `#1B1F27` |
| 面板 `--panel` | `#FFFFFF` | `#252A32` |
| 舞台 `--stage` | `#DCE2EA` | `#12161C` |
| 弱底 `--well` | `#F0F3F7` | `#2C3340` |
| 文字 `--text` | `#20262E` | `#E8ECF2` |
| 次要 `--muted` | `#5F6B7A` | `#9BA6B5` |
| 线 `--line` | `#C9D1DB` | `#3A4452` |
| 强调 `--accent` | `#0F6CBD`（Win 蓝） | `#60A5FA` |
| 危险 `--danger` | `#C42B1C` | `#FF6B5A` |

**字号 / 控件**

| 项 | 值 |
|----|-----|
| 正文 | 12px / 13px（中文优先 13） |
| 文件名 | 13px 半粗 |
| 次要/单位 | 11px |
| 按钮/输入 | 高 28px，padding 0 10px，圆角 6px |
| 图标按钮 | 28×28，图标 16px |
| 标签高 | 36px |
| 操作条 | 36px |
| 页码条 | 28px |
| 间距节奏 | 4 / 8 / 12 |

**图标**：内联 SVG（文件夹、打印、全屏、放大缩小、齿轮、关闭、加号）。禁止 emoji。

**动效**：仅 120ms 背景/透明度；`prefers-reduced-motion: reduce` 时关闭。

## 4. 分屏设计要点

### 4.1 首页
- 无大标题；中间 **单一主按钮「打开文件」** + 小字「或将文件拖到此处」  
- 下方一行低调格式：`Word · Excel · PPT · PDF · 图片 · 文本`  
- 右上角齿轮（设置）  
- 拖入时整窗 1px 蓝描边，不使用大遮罩蒙层  

### 4.2 多标签预览
- 标签：类型色点 + 短文件名 + ×；选中白底 + 顶 2px accent  
- 长文件名：标签内省略，悬停 tooltip  
- 操作条顺序：缩放 −/+/数值 → 适合宽度/整页/100% → 页码 → 分隔 → 打印（仅 PDF/图/DOCX）→ 沉浸  
- 沉浸：操作条与页码条贴边淡出，鼠标靠边显示；Esc/F11 退出  

### 4.3 打印窗（重点）
```
打印机 [ApeosPort… ▾]     彩色 双面     [并排] [系统打印机]
────────────────────────────────────────
☑ 合同.pdf              A4 纵 1份 全部  [设置]
  [小纸张示意]  1 页 · A4 210×297 mm
  （展开后：纸张/方向/份数/单双面/颜色/缩放/页序/页码）

☑ 发票合集.pdf          A5 横 2份 1-3  [设置]
…
────────────────────────────────────────
已提交≠出纸        [添加文件]  [打印所选文件 (2)]
```
- 一行摘要替代多胶囊  
- 状态用文字+图标：等待 / 提交中 / 已提交队列 / 失败：原因 / 未勾选  
- 不出现未实现的“驱动能力检测”或“纸面可视化预览”（若代码没有）  

### 4.4 设置
- 单列、短标签、无说明段落  
- 分组：外观 / 启动 / 多文件 / 打印入口
