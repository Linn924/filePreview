# PDF 增强实施与验收

2026-09-30。用户授权桌面建议文档除 **01 双页并排视图** 外的全部优化；文档中的示例实现、分期、推测收益作为参考，不直接当成代码事实。此批次只改源码和测试，不做全量测试、安装包、卸载/安装或实体打印。

| 编号 | 实施结果与取舍 | 验收 |
| --- | --- | --- |
| 02 无文字层提示 | 全篇检索确认字符总量为零后提示疑似扫描件，避免前五页为空误判；不添加 OCR | 无文字 PDF 搜索提示；普通文本仍可搜索 |
| 03 目录搜索 | 目录标题实时过滤，保留匹配项父链，过滤时暂时展开；清空恢复原折叠状态 | 标题命中、目的页跳转、无结果提示 |
| 04 命中对齐 | 同一 TextItem 映射供字符串提取/DOM span 使用，保存精确 start/end；清理旧 mark 后再高亮 | 空文字项/marked content、特殊空格、Unicode、DOM 命中 |
| 05 动态缓存 | 每份共享文字/搜索缓存按文档页数 40% 调整，32–128 页、4–16 MB；活动提取保持引用保护 | 120 页取消/换词/2400 命中、缓存上下限 |
| 06 中心调度 | 正文直接入队，按离当前阅读页的距离排序，前景优先级小于 1；不再用 Promise 串行链挡住排序 | 既有前景/后台调度断言与长文档跳页 |
| 07 画布热路径 | 像素按分配/释放增量记账；余额常量查询，DOM 清理在虚拟节点/标签可见性/预算变化触发 | 50 次余额查询无 DOM 访问、重分配/幂等释放、多窗口预算 |
| 08 批注 PNG | 用户显式保存当前页，完整页面+临时高亮+页边备注；临时计费画布，最大 600 万像素/8192 长边/32 MB；保存取消不写文件，不能覆盖打开的源文件 | PNG 有效性/尺寸、保存/取消、源路径保护；不导出整个文档 |
| 09 矩形合并 | 归一化后只合并交叠 80% 以上且相邻约 2 CSS px 的矩形，兼顾旋转和跨列；不承诺固定 70% 压缩率 | 邻片/重复片合并、分行/分列不串合、旋转逆变换 |
| 10 批注空状态 | 已有操作指引补充主动导出与关闭清空说明 | 清空重开、导出入口禁用 |
| 11 打印回执 | 主进程返回提交/取消/驱动失败结构，UI 用不同状态颜色；保留驱动原因，准备失败仍单独报错 | 模拟 cancelled、驱动端口异常、重试和图片/DOCX 协议 |
| 12 旋转恢复 | 沿用文件内存 view.rotate，不改存储；补齐卸载标签和跨窗口移交后的画布/文字验证 | 切换到文本并卸载，返回及跨窗恢复 90° |
| 13 平移光标 | 原有 grab/grabbing 提高选择器优先级并覆盖文字/链接子层；演示时禁用平移 | 真实空格/中键拖动、演示空格翻页 |
| 14 阅读快捷键 | Home/End、Ctrl 加减/0、Ctrl+滚轮、R/Shift+R；倍率 25–400、每次 10%；输入控件不劫持，普通滚轮不缩放 | 页码/倍率/方向和输入框隔离 |
| 15 大小写 | 显式 Aa 开关，开关重检当前查询，默认忽略大小写 | Local/local 精确区分、Unicode 源偏移 |
| 16 目录页码 | 既有页码弱化标注补充 class/可访问标签，不伪造解析失败项页码 | 目标页码与跳转一致 |
| 17 演示模式 | 独立按钮/Ctrl+Shift+P，单页整页适配、黑底、原生全屏、无控制栏；左右键/空格/鼠标左右键翻页，Esc 退出并恢复先前全屏状态及阅读倍率/适配 | 原生全屏、前进后退、单页比例、退出恢复、真实键盘入口 |
| 18 模式搜索 | 明确普通/通配符/正则下拉；普通模式保留符号字面意义；模式搜索可终止 Worker，每页 1 秒 deadline，最多 512 表达式字符/50000 命中，忽略零长度匹配 | 通配符单号、正则、无效表达式、高代价表达式超时及恢复 |
| 19 邻页预热 | 百页以上空闲预热 ±10 页尺寸，低优先级；滚动/关闭取消本使用者，不影响共享读取。现有全篇后台尺寸扫描仍保留 | 共享预热取消隔离、长文档虚拟化/跳页 |

双页并排不实施。演示通过单页虚拟窗口实现，无需双页行模型。目录深度由现有大纲解析提供；尺寸预热不重复扫描大纲树。批注导出是此轮明确授权的主动输出，不自动保存预览副本或路径历史。表达式不自动由输入标点切换模式。

## 验证记录

最终通过：类型检查；`pdfenhancements,pdf,pdfchain,printing,core` 专项（含基础逻辑单测、应用退出检查）；最终搜索偏移补强后重新构建并通过 `pdfenhancements,pdf`，新增缓存/混合文字与扫描件断言通过。既有样例 SHA256 不变。新增 PNG 已目视检查页面文字、标记位置及页边备注。

专项性能分别运行 `FILE_PREVIEW_PERF_PHASE=enhancements`、`FILE_PREVIEW_PERF_SCENARIO=long-500 / dense-20`、`npm test -- --skip-build --suite pdfperf`，结果写入忽略目录 `outputs/bench/pdf-chain-enhancements.json`，保留上一批次 after/before 文件。

中间失败与修正：旋转断言按横向样例正确检查旋转后的纵向比例；测试单独关闭后台节流避免遮挡暂停帧；模式切换后等待先前搜索结束再点击查找；高代价正则样例采用可提取的页面内字号，避免实际只提取少量字符；首次 SHA 差异来自本轮合成样例脚本调整后的重新生成，稳定样例重跑通过。预热共享尺寸取消隔离和 Unicode 部分大小写展开由审查补强并验证。

测试只构建所需运行资源；没有安装包/ZIP、卸载、安装或实体打印。未证明所有字体、真实打印驱动/纸盒/出纸及全部文档形态；PNG 是当前页图片，不是可重新编辑的批注文件。
