# 打印需求与当前实现

更新日期：2026-09-28 · 当前项目版本：3.3.4。完整能力清单见 [当前功能说明](FEATURES.md)。

1. 提供 PDF、图片和 DOCX 打印，单文件及多文件均可；暂不限制多选数量和打印列表数量。DOC、Excel、PPT 和纯文本暂不提供打印。
2. 点击预览工具栏打印入口时，按设置决定列表内容：**本窗口全部可打印文件**（默认）、**仅当前文件**、**不自动加入**。同一文件 ID 不重复添加。
3. 打印设置是独立非模态窗口，可通过系统标题栏移动、缩放或放到另一显示器。原 PDF 可继续滚动/缩放，没有弹层遮罩。“并排查看”将两个窗口左右摆放。
4. 统一窗口汇总所有待打印文件。每个文件下方配置自己的纸张（A3/A4/A5/A6/Letter/Legal）、方向、份数（1–99）、页码、颜色、单双面、缩放（适合纸张/实际大小/仅缩小）和页序（顺序/逆序/奇数页/偶数页），打印机为批次公共设置。
5. 可勾选、排序、移除、折叠设置；摘要保留。“应用到全部”复制当前文件的参数，不关联后续编辑。
6. 点击文件名联动原预览；原预览关闭时可重建。显示第 1 页原始尺寸、总页数、所选纸张尺寸。屏幕缩放不代表实际纸张尺寸；混合尺寸文档每页仍按原比例适配打印。
7. 一次点击“打印所选文件”，冻结本批次各文件参数并顺序提交。失败显示原因并继续，停止后续任务不撤回系统已接收的任务。
8. 添加按钮和外部可打印文件拖入均支持；不同预览 Tab 的打印入口汇入同一打印窗口。打印中收到其他 Tab 添加请求时，待当前批次结束再加入。新条目默认折叠，展开时才准备纸张预览。
9. 原文件不修改、不上传。列表、打印参数和尺寸信息仅保存在本次内存会话中，关闭打印窗口即释放。Windows 打印后台缓存与驱动行为不由应用控制。

边界：目前原页尺寸展示第 1 页；不提供全部页的纸张排版预览；不能把“提交成功”视为实体出纸完成。非 A4 纸张的兼容性提示基于纸张与打印机信息，并非真实能力检测；实际纸张、纸盒、彩色及单双面由驱动与设备支持情况决定。屏幕缩放与打印缩放独立。单文件体积、打印画布内存等已有资源限制继续有效。

PDF 输出仍为 150 DPI；实际大小保持原比例，超出内容区域时居中裁切，画布只分配最终可打印区域。纸张示意与输出共用 `src/modules/pdf/print/rasterPlan.ts`，避免 CSS 再次缩小原尺寸。任务有独立标识，旧/重复通知不结束或重提下一份任务；专属打印窗口的字节可直接交给解析器，其他任务和原预览保持独立。解锁密码仅随当前文件引用保留在内存，用于允许的打印，不写设置、文件或历史。
