# 打印需求与当前实现

1. 只提供 PDF 打印，单文件及多文件均可；暂不限制多选数量和打印列表数量。
2. 点击预览工具栏“打印 PDF”时，按设置决定列表内容：**本窗口全部 PDF**（默认）、**仅当前文件**、**不自动加入**。同一文件 ID 不重复添加。
3. 打印设置是独立非模态窗口，可通过系统标题栏移动、缩放或放到另一显示器。原 PDF 可继续滚动/缩放，没有弹层遮罩。“并排查看”将两个窗口左右摆放。
4. 统一窗口汇总所有待打印 PDF。每个文件下方配置自己的纸张（A3/A4/A5/A6/Letter/Legal）、方向、份数、页码、颜色和单双面，打印机为批次公共设置。
5. 可勾选、排序、移除、折叠设置；摘要保留。“应用到全部”复制当前文件的参数，不关联后续编辑。
6. 点击文件名联动原预览；原预览关闭时可重建。显示第 1 页原始尺寸、总页数、所选纸张尺寸。屏幕缩放不代表实际纸张尺寸；混合尺寸文档每页仍按原比例适配打印。
7. 一次点击“打印所选文件”，冻结本批次各文件参数并顺序提交。失败显示原因并继续，停止后续任务不撤回系统已接收的任务。
8. 添加按钮和外部 PDF 拖入均支持；不同预览 Tab 的打印入口汇入同一打印窗口。打印中收到其他 Tab 添加请求时，待当前批次结束再加入。
9. 原文件不修改、不上传。列表、打印参数和尺寸信息仅保存在本次内存会话中，关闭打印窗口即释放。Windows 打印后台缓存与驱动行为不由应用控制。

边界：目前原页尺寸展示第 1 页；不提供全部页的纸张排版预览；不能把“提交成功”视为实体出纸完成。单文件体积、打印画布内存等已有资源限制继续有效。
