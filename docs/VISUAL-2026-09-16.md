# 多格式预览视觉优化

范围：公共工具栏、搜索行、Excel 工作表区域、Markdown/文本主题、PDF 目录缩略图、图片放大视图。

基线检查：在 960×640 内容尺寸、125% 页面缩放下，PDF 展开搜索后工具栏溢出 138 CSS 像素，目录、旋转、打印及沉浸按钮被裁切；Excel 有额外 16×20 px 外围留白，工作表与定位/冻结控件混排。

实现：公共容器增加 search-tools 插槽，PDF/文本通过 Teleport 注入独立搜索行，开启后聚焦、Esc 关闭；工具栏允许换行且按钮文字不拆行。Excel 分离工作表与定位/冻结行并去除外边距。PDF 缩略图与目录按钮改为内容自适应高度。统一阅读背景；改善 Markdown 表格/引用、暗色语法高亮和文本字体继承。修改均在公共组件或相应格式模块内部。

测试：visual 套件保留优化前/后截图和可见区域指标；同时运行原有相关功能回归。未改变文件解析、打印纸张设置及源文件内容。真实打印与多显示器 DPI 切换不在本批次验证范围内。

随后完成内存与样式小批次：文件选择先保留元数据、当前标签按需读取，切换后释放渲染树；打印列表的折叠行不再生成纸张示意，图片/PPT/Word 删除重复覆盖的 CSS。源路径只在应用进程的内存中保留，用于本次会话切换或打印时重新读取。
