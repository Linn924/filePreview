## 工程与质量（当前缺口）

| 优先级 | 内容 | 说明 |
| --- | --- | --- |
| P1 | 真实大文件性能基准 | 现有 80 页合成样例不能代表百页混合/万行 Excel；需要前后耗时与内存对比脚本 |
| P1 | 本机安装包验收 | 安装、卸载、Open With、托盘、设置持久化未在本轮安装路径上实机跑完 |
| P2 | 安装包代码签名 | 未商业签名，SmartScreen 可能拦截；需要证书与流水线 |
| P2 | 实体打印机验收 | 自动化仅拦截 print 并做内存 PDF；驱动、纸盒、双面需实机 |
| P2 | ResizeObserver 偶发警告 | 长 PDF 调窗口仍可能触发；未宣称已修复，需复现与根治 |
| P2 | 超多页 PDF DOM | 每页仍建占位元素，极大页数未做虚拟列表 |
| P2 | 打印入口/多窗口测试稳定性 | 多开打印窗口时序依赖较强，改打印面板时回归成本高 |
| P3 | 打印未签名路径下的 SmartScreen 文案与用户引导 | README 可补充 |

本轮边界：先加交付校验与可配置打印入口；安装包校验不能替代安装测试、签名或内容安全审计。

## 打印后续增强

已实现独立打印窗口、每文件独立设置、预览联动、并排查看，以及打印入口策略（默认本窗口全部 PDF）。后续可增加混合尺寸文档逐页尺寸浏览、纸张上的可视化排版预览，以及打印机能力自动检测；目前不代表已支持这些功能。

## 标签移动状态的进一步保留

当前版本已有：跨窗口拖入合并、目标确认后移除源标签、同窗切换/排序/关闭、保留缩放与常规滚动位置。

后续可增强：

- 已实现迁移适配方式、Excel 工作表/列分组/已加载行、文本编码和临时列宽；Word 表格临时列宽迁移仍待开发。
- 空窗口、最后一个标签、关闭与拖动并发时有明确行为。
- 测试两窗互拖、排序、关闭、转移失败回滚、大文件内存释放及主题同步。

## 文档兼容性样例库

持续收集无隐私的最小复现文件，优先针对真实出现的 PPT、Word 复杂表格与特殊字体问题建立回归。每次修复仅声明经过验证的范围。
