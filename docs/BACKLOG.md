# 后续功能

以下为规划，不代表当前版本已实现。

## 跨窗口拖动并合并标签页

目标：将一个预览窗口/标签拖入另一个预览窗口，把内容合并到目标窗口，在内部标签页切换；标签可拖动排序、关闭，也可拖出成为新窗口。

当前版本已有：首次多文件打开时选择同窗标签或独立窗口；同窗标签切换、排序、关闭。

下一步需要设计：

- 主进程维护文档 ID 与窗口的归属关系，以临时内存交付方式转移内容，不写转换副本。
- 跨窗口拖入时先确认接收成功，再销毁原视图；失败必须保留原窗口。
- 迁移缩放、页码、滚动位置和临时列宽；不能重复解析后悄悄重置状态。
- 空窗口、最后一个标签、关闭与拖动并发时有明确行为。
- 测试两窗互拖、排序、关闭、转移失败回滚、大文件内存释放及主题同步。

## 文档兼容性样例库

持续收集无隐私的最小复现文件，优先针对真实出现的 PPT、Word 复杂表格与特殊字体问题建立回归。每次修复仅声明经过验证的范围。
