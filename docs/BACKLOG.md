## 未来可新增功能

| 优先级 | 功能 | 说明 |
| --- | --- | --- |
| 高 | 全局文件搜索 | 在打开过的标签/文件夹内容中搜索（仍不落盘历史） |
| 高 | PDF 批注/高亮标记（内存） | 不写回源文件；关闭即丢或导出 PNG |
| 高 | 拖拽合并到任意 Tab 区（已完成跨窗） | 可再加「拖到标签栏插入位置」 |
| 中 | CSV/TSV 导出/另存副本 | 用户主动导出，非静默写盘 |
| 中 | 打印预览分页动画/逐页检查 | 打印窗口内更像 Word 的预览 |
| 中 | 多显示器记住窗口布局 | 关闭重开恢复位置 |
| 中 | 快捷键大全 / 命令面板（Ctrl+K） | 切换文件、搜索、打印、主题 |
| 低 | 插件式格式模块 | 更容易加新格式（已有 modules 雏形） |
| 低 | Electron → Tauri 2 | **硬门槛：打印**；见校验文档，未过门禁不迁 |

## 边界（长期不承诺）

- 不保存预览副本、路径历史  
- 不依赖 Office 安装  
- 实体出纸以驱动为准；「已提交」≠ 出纸成功  
- 扫描版 PDF 无文字层则搜不到
