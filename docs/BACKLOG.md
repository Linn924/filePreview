# 后续功能

以下仅记录未完成的增强方向。

## 打印后续增强

已实现独立打印窗口、每文件独立设置、预览联动和并排查看。后续可增加混合尺寸文档逐页尺寸浏览、纸张上的可视化排版预览，以及打印机能力自动检测；目前不代表已支持这些功能。

## 标签移动状态的进一步保留

当前版本已有：跨窗口拖入合并、目标确认后移除源标签、同窗切换/排序/关闭、保留缩放与常规滚动位置。

后续可增强：

- 迁移 Excel 工作表、文本编码和临时列宽；不能重复解析后悄悄重置状态。
- 空窗口、最后一个标签、关闭与拖动并发时有明确行为。
- 测试两窗互拖、排序、关闭、转移失败回滚、大文件内存释放及主题同步。

## 文档兼容性样例库

持续收集无隐私的最小复现文件，优先针对真实出现的 PPT、Word 复杂表格与特殊字体问题建立回归。每次修复仅声明经过验证的范围。
